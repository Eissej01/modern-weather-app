
# 🌤️ Modern Weather App

A sleek, responsive, and feature-rich weather web application built with vanilla JavaScript, HTML5, and CSS3. It features a modern glassmorphic design that dynamically changes its visual theme and custom vector graphics based on real-time weather conditions.

## ✨ Features
- **Dynamic Themes & SVGs**: Automatically changes background gradients and custom weather icons (Clear, Clouds, Rain, Drizzle, Mist, Snow) depending on the live condition.
- **Glassmorphism UI**: Modern translucent card design with backdrop filters and smooth transitions.
- **Metric & Imperial Toggle**: Switch seamlessly between Celsius (°C) and Fahrenheit (°F) with live temperature conversion.
- **Responsive Design**: Optimized for both mobile and desktop viewports.
- **Error Handling**: Graceful error notifications for invalid city names or network issues.

## 🔗 Weather API
This project uses the **[OpenWeatherMap API](https://openweathermap.org/api)** to fetch real-time weather data, humidity levels, and wind speeds.
